Mode: Experience (a portfolio: the work itself leads from the first viewport).

## Direction contract

THESIS: The portfolio is a small personal computer, markOS, whose Music app plays Mark's album *Simple, Complicated*, and each track opens a section window. It refuses the category default of a name hero over a project card grid.
OWN-WORLD: A soft pastel wallpaper (periwinkle → pink → butter, with film grain), and at night the same hues deepened to ink-violet. Crisp white or ink windows with 10px corners, a 1px edge and a soft offset shadow. Bricolage Grotesque for display and UI, IBM Plex Mono only for data (clock, filenames, track numbers, durations). One accent, a pressed-berry pink. Folder and app icons are authored SVG.
STORY: A visitor sees a desktop, not a website, reads "Hi, I'm Mark Panolin" and the lol line in hello.txt, notices the album, clicks the ★ title track, and Projects opens as a folder of live sites. Contact is one click from hello.txt.
FIRST VIEWPORT: Desktop: a menubar across the top (markOS menu at left; clock, theme and sound at right). hello.txt is large at upper left, about 44% wide. The Music window sits at mid-right, overlapping slightly. A sticky note is at lower left, and four folder icons run down the right edge. The primary action, "Open Projects ★", is in hello.txt. Phone: status bar, hello widget, app grid.
FORM: user-pinned markOS desktop (brainstorm option 1, approved spec). seed: none (roll skipped: the user pinned the direction in brainstorming before Impeccable was invoked; a pinned direction beats the roll).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
